Caught red-pawed, the dog offers no apology — it read the homework first, found the answers wrong, and fixed them the only way a dog knows how: by eating it. In its own telling, this was not mischief but a rescue mission that saved the grade.

## Run it

```bash
python3 main.py
```

This prints the entry and writes it to `/output/entry.txt`.
